# DermaFlow SEO audit

## Completed

- Descriptive page title focused on skincare intent.
- Meta description written for calm, hydrated skincare routines.
- One clear `h1`, followed by structured product section headings.
- Product images have descriptive `alt` text.
- Open Graph title, description, and product preview image.
- Twitter summary-large-image metadata.
- Organization JSON-LD structured data.
- Dedicated `shop.html`, `routine.html`, `story.html`, and `faq.html` pages with descriptive titles and internal links.
- Six-product Shop catalog with category-specific product copy and local image assets.
- `robots.txt` with sensitive backend files excluded.
- Apache security headers and asset caching defaults in `.htaccess`.
- Local generated images avoid third-party hotlinking.

## Before launch

- Replace relative social image URLs with absolute URLs after the Hostinger domain is known.
- Add a canonical URL using the final HTTPS domain.
- Create `sitemap.xml` using the final domain and submit it in Google Search Console.
- Test the public page with Lighthouse or PageSpeed Insights.
- Verify PHP/MySQL API responses on the deployed host.
- Keep real payment processing disabled until a secure provider, server-side validation, and webhook handling are implemented.
